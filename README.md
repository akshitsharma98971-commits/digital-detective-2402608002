## Assignment Overview
The **Digital Detective** assignment is a hands-on exploration of computer systems, command-line operations, operating system internals, program execution, number systems, version control with Git & GitHub, and computer networking.

Each mission focuses on an essential concept in computer science and system administration, accompanied by practical exercises, observations, and structured reflections. All missions are strictly developed, documented, and committed sequentially.

---

## My Learning
Through the hands-on missions completed in this investigation, several fundamental computer science insights have been solidified:
1. **The IPOS Cycle and Hardware-Software Interaction:** Tracing real tasks from physical input interrupts through memory and CPU processing down to non-volatile flash storage demonstrated how physical transistors and abstract software instructions coordinate seamlessly.
2. **Command-Line Precision and Safety:** Working directly in the shell reinforced the critical distinction between overwriting files (`>`) versus appending data (`>>`), utilizing standard stream pipes (`|`) for data transformation, and inspecting Unix permissions (`rwx`) to maintain secure environments.
3. **Number Systems and Machine Representation:** Converting values manually between decimal, binary, and hexadecimal proved how computers represent complex instructions and data strictly with bits and bytes, bridging abstract human numbers and physical machine registers.
